# Research North Star

Build a deterministic workspace for searching for common structure across multiscale physics, learned dynamics, and intervention-aware control without overstating current maturity.

## Current anchor

The current executable anchor is periodic 2D grid turbulence with invariant summaries and config-driven rollout execution.

## Near-term search questions

- Which invariants must be exact versus merely monitored?
- Which closure targets improve long-horizon behavior rather than only one-step loss?
- Which intervention policies stabilize rollouts without hiding physical error?
